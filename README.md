# Honey

**Honey** — это мой личный проект, объединяющий три темы:

- **Пчеловодство** — заметки о мёде, ульях и медоносах.
- **Родительская школа** — опыт создания семейного сообщества.
- **Дневник радости** — ежедневные записи о счастливых моментах.

Название **Honey** символизирует сладость жизни и увлечение пчеловодством.

## Структура

- `_posts/` — все записи (категории: `пчеловодство`, `родительство`, `радость`).
- `index.md` — главная страница сайта (Jekyll).
- `assets/` — изображения.
